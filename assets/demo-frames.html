Get started in 3 steps

Own a browser, log in once, ask away.

1
Install
npm install · npx playwright install chromium · npm run build. The server owns its own Chromium — it does not touch your everyday browser.
2
Log in once
npm run login opens a window. Sign in to instacart.ca once; the session is saved and survives restarts.
3
Register & ask
Add it to your MCP host (~/.mcp.json), then just ask: "compare ground beef across stores."
